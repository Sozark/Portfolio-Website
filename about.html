About

// IDENTITY

Noah C. Jones

Full-Stack Web Developer · Design Engineer

// BIO.txt

I'm a full-stack web developer with a B.S. in Computer Science from LSU and a minor in Digital Media Arts & Engineering. I build web applications end-to-end, from database and API design through responsive front-end code and deployment, using React, Node.js, ASP.NET Core, and SQL Server.

My IT background informs how I build. As an IT intern at Baton Rouge STEM, I led a website redesign that grew program registrations 250% (20 to 70+), built Python and C# automation tools, and supported CI/CD pipelines and Windows systems. As an independent developer, I take client projects from requirements to launch, including StayFinder AI, NJEM, and Sidéral.

I also bring design and accessibility experience to development work. I build to WCAG/ADA standards, and BandBuilder, an accessibility-first music game for children with autism, was usability tested with users ages 5–8. I led the team behind Bubble Hero, which won 1st Place, Best Overall Game at a Global Game Jam.

I'm looking for full-stack web developer and design engineer roles where I can build reliable products and work closely with the people who use them. I'm based in New Orleans and open to relocation.
